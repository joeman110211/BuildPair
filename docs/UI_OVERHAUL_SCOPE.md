# BuildPair public-product UI overhaul

This short-lived feature branch is the professional design/content pass requested before UK launch.

## Scope

- modernise the public homepage and navigation
- make the homepage explain the complete BuildPair proposition instead of behaving like a thin directory
- show the agreed Starter / Plus / Pro pricing clearly without inventing VAT or annual billing decisions
- remove stale trial wording
- improve homeowner and tradesperson product pages
- strengthen About, How It Works, Trust & Safety and public policy information
- improve visual hierarchy, spacing, colour, cards and calls to action
- replace weak generic homepage imagery with relevant home-improvement/project imagery
- repair the dashboard settings action so it is a clear labelled control rather than relying on a fragile icon-only button
- keep the cross-platform app responsive and accessible

All product claims must match the BuildPair project handover / product overview and current implementation. Production release remains gated by CI, E2E, real-device QA, payment configuration, hosting and app-store readiness.
